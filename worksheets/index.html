How to use these properly

Tracing is not copying. The point is the motor trace, and a motor trace only forms if the hand moves in the correct stroke order at a steady speed. Rushing produces a fast wrong habit that takes longer to remove than it took to build.

Say it while you write it. Component keywords → mnemonic → meaning, out loud. Hand, mouth and eye on one pass is three encoding channels for the price of one.

Cover the model before the blank boxes. The blanks are a retrieval test. If you copy from the model, you have done zero retrieval and the sheet was decoration.

Mark your own errors. Circle any character you had to peek at, and write the count in the Errors box. Those are the characters that go into the next trap drill.

Font note: these sheets request UD Digi Kyokasho, the Japanese school-textbook font included with Windows 11, so the shapes you trace are the handwritten forms rather than the print forms. If characters look like a serif print face instead, the font is missing — tell Claude and it will switch the stack.
